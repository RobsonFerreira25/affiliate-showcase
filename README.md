# QPA — Quem Procura Acha

Bem-vindo ao repositório do **QPA**, a central definitiva de achados e ofertas dos principais marketplaces do Brasil.

## 🚀 Sobre o Projeto

O QPA é uma plataforma de vitrine de afiliados focada em curadoria de ofertas reais da Amazon, Mercado Livre e Shopee. O sistema oferece uma interface premium, responsividade de alta performance e filtros inteligentes para facilitar a busca pelo menor preço.

## 🛠️ Tecnologias Utilizadas

- **Vite** + **React**
- **TypeScript**
- **Tailwind CSS**
- **Supabase** (Banco de dados e Autenticação)
- **TanStack Query** (Gerenciamento de Estado de Servidor)
- **Lucide React** (Ícones)
- **Shadcn UI** (Componentes de Base)

## 📦 Como Rodar Localmente

1.  **Clone o repositório**:
    ```sh
    git clone <YOUR_GIT_URL>
    ```
2.  **Instale as dependências**:
    ```sh
    npm install
    ```
3.  **Inicie o servidor de desenvolvimento**:
    ```sh
    npm run dev
    ```
